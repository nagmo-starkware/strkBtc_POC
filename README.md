# BTC Bridge POC

Proof of concept for a bridge between Bitcoin and Starknet.

## Overview

This POC explores the feasibility of bridging BTC to Starknet and back, enabling Bitcoin holders to interact with the Starknet ecosystem.

## Architecture

- **Smart Contracts** (`/contracts`) — Cairo contracts deployed on Starknet
- **Backend** (`/backend`) — Rust service handling Bitcoin network interactions
- **Documentation** (`/docs`) — Architecture decisions and specifications

## Tech Stack

- **Cairo** — Starknet smart contracts
- **Rust** — Bitcoin integration backend
- **Bitcoin** — Source chain
- **Starknet** — Destination chain
